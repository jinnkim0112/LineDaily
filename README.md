
# 🖌️ Line Daily (라인 데일리)

하나의 거대한 캔버스 위에 모든 사용자가 획을 더해가는 실시간 협업 아트 프로젝트입니다. r/place에 영감을 받아서 만들었으며, 픽셀 대신 **'선의 흐름'**에 집중합니다.

---

## 🕹️ 규칙 (The Rules)
- **공동의 작품:** 모든 사용자는 동일한 캔버스를 공유합니다. 누군가는 예술을 만들고, 누군가는 낙서를 할 수도 있습니다.

**하루 그리기 구역:** 하루에 한 번, 각 사용자는 전체 1만x1만 픽셀의 거대한 캔버스 중 임의의 100x100 픽셀 구역을 선택해 그 구역 안에서만 무제한으로 선을 그릴 수 있습니다. (다음 날이 되면 새로운 100x100 구역을 선택할 수 있습니다)

---


## 🛠️ 핵심 기술 구현 (Simplified Stack)
- **Frontend:** React + HTML5 Canvas
- **Real-time Logic:** Supabase Realtime (Postgres 기반 실시간 좌표 공유)
- **State Management:** 캔버스 전체의 좌표 데이터를 배열로 관리하여 실시간 동기화

---

## 📐 데이터 구조 (Example)
하나의 획(Stroke)은 다음과 같은 데이터로 구성되어 DB에 저장됩니다.

```json
{
  "userId": "user_123",
  "points": [[x1, y1], [x2, y2], [x3, y3]], // 선의 궤적
  "color": "#000000",
  "timestamp": "2026-01-31T01:18:00Z"
}
```

---

## 🚀 주요 기능
- **Live Canvas:** 다른 사람이 긋는 획이 실시간으로 화면에 나타납니다.

- **Daily Stroke Limit:** 하루에 그릴 수 있는 총 선 길이 제한(100x100 화면 크기 기준)이 적용됩니다.

- **History Playback:** 첫 번째 획부터 지금까지 어떻게 변해왔는지 타임랩스로 확인합니다.

---

## 📦 시작하기 (Getting Started)
1. 이 저장소를 클론합니다.
2. Supabase 프로젝트를 생성하고, Realtime 기능을 활성화합니다.
3. `.env` 파일에 Supabase 설정을 입력합니다.
4. `npm install`로 의존성을 설치합니다.
5. `npm start`로 개발 서버를 실행합니다.

## 🔧 구현 노트 (Implementation Notes)

### 타일 렌더링 (10,000 x 10,000 캔버스)
- 전체 월드는 10k x 10k로 유지하되, 화면에 보이는 **타일(기본 512px)**만 렌더링합니다.
- 각 타일에 stroke 데이터를 캐싱하고, 변경된 타일만 다시 그립니다.
- 이 방식은 메모리/성능을 안정적으로 유지하면서 큰 캔버스를 지원합니다.

### 선 데이터 간단화 (Stroke Simplification)
- 입력 중에는 **최소 거리 샘플링**으로 점 개수를 줄입니다.
- 입력 종료 시 **Ramer–Douglas–Peucker(RDP)** 알고리즘으로 최종 점을 간단화합니다.
- 이중 간단화 방식으로 긴 선의 데이터 크기를 크게 줄이고, 모양은 최대한 유지합니다.

### 사용자 식별 (로그인 없이)
- 브라우저에서는 MAC 주소를 가져올 수 없기 때문에 **localStorage 기반 UUID**를 사용합니다.
- 동일 기기/브라우저에서는 동일 ID, 다른 기기에서는 다른 ID가 생성됩니다.

### Supabase 환경변수 분리
- `.env.local`에 다음 키를 넣고 Git에 올리지 않습니다.

```
VITE_SUPABASE_URL=...
VITE_SUPABASE_ANON_KEY=...
```

- `.gitignore`에 `.env.local` 추가 필요
- Cloudflare Pages에는 동일한 키를 환경변수로 등록

### Supabase 테이블 스키마 (strokes)
- 한 stroke는 여러 타일에 복제되어 저장됩니다. (tile_x, tile_y로 조회 최적화)

```sql
create table if not exists strokes (
  id bigint generated by default as identity primary key,
  stroke_id uuid not null,
  user_id text,
  points jsonb not null,
  color text not null,
  width numeric not null,
  tile_x int not null,
  tile_y int not null,
  created_at timestamptz default now()
);

create index if not exists strokes_tile_idx on strokes(tile_x, tile_y);

alter table strokes enable row level security;

create policy "public read" on strokes
for select using (true);

create policy "public insert" on strokes
for insert with check (true);

create policy "public delete" on strokes
for delete using (true);

-- Required for realtime delete payloads to include old row data
alter table strokes replica identity full;
```
